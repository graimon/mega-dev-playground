# mega-dev-playground

This repo holds the GitHub work for Challenges of the [MEGA.dev course](https://hq.mega.dev).
Each Challenge that needs a public GitHub repo gets its own folder, named after the Challenge code.

| Folder | Challenge | State | Issues |

Each folder has its own `README.md` with the task, the files and the result.

## How a Challenge uses this repo

1. A folder named after the Challenge code holds all the files, for example `s01e04/`.
2. The repo's GitHub issues are the Challenge's tickets. Put the Challenge code in each new issue
   title, for example `[S01E04] …`, so the issue list shows which Challenge owns each issue.
3. When the course requires a fixed layout, the files can sit at the repo root during the solve.
   After the course accepts the Challenge, the files move into the Challenge folder.
4. After the solve, the folder's `README.md` is marked archived, and this table gets a new row.

Issue numbers are shared by all Challenges, so the table lists the issues for each folder.
